# 投資風格測驗

10 題情境測驗，找出適合你的投資方式（定存、基金、ETF、個股）。

## 測驗內容

測驗從兩個方向評估：

- **風險承受度**（5 題）：遇到虧損時的反應、能接受的波動幅度。
- **投入程度**（3 題）：願意花多少時間研究、對投資的了解。

另外有 2 題資金狀況題（緊急預備金、資金多久會用到）。資金狀況不佳時，建議配置會往定存調整。

結果分為四種類型：

| 類型 | 主要配置 |
|---|---|
| 穩健保守型 | 定存 |
| 穩健託付型 | 債券型或平衡型基金 |
| 被動成長型 | 大盤型 ETF |
| 積極研究型 | 個股搭配 ETF |

## 使用方式

整個測驗只有一個檔案。直接用瀏覽器打開 `index.html` 就能使用，不需要安裝任何東西。

推送到 `main` 後，`.github/workflows/deploy.yml` 會自動部署到 GitHub Pages。第一次使用請到 Settings → Pages，把 Source 設為「GitHub Actions」。

## 修改內容

題目、計分方式、各類型的配置比例和說明文字，都在 `index.html` 最下方的 `<script>` 區塊裡：

- `QUESTIONS`：題目與選項
- `TYPES`：四種類型的說明與配置比例
- `compute()`：計分與資金狀況調整的規則

## 聲明

本測驗僅供參考，不構成投資建議。
